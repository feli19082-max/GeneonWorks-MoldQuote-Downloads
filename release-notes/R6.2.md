## 安装

1. 下载 `GeneonWorks-MoldQuote-R6.2-win-x64.zip`；
2. 完整解压 ZIP，不要直接在压缩包中运行；
3. 运行 `GeneonWorks.MoldQuote.Desktop.exe`；
4. Windows 首次运行时如显示安全提示，请确认文件来源后选择继续。

## 系统要求

- Windows 10/11 x64；
- 保留完整解压目录中的 OCCT 原生运行组件；
- 建议安装当前受支持的 .NET 8 Desktop Runtime。
